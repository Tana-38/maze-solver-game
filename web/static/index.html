04

Method

i

Generate

Randomized DFS walks to an unvisited neighbor, knocks down the wall between them, and backtracks at dead ends. The carved edges form a spanning tree, so |E| = |V| - 1 and there is exactly one route between any two cells.

O(|V|)

ii

Braid

Adding any edge to a tree closes exactly one cycle. Higher difficulties remove a few extra walls this way, which creates loops and makes shortest paths matter.

cycles = |E| - |V| + 1

iii

Solve

BFS explores the graph in layers of equal distance, so the first time it reaches the exit it has a shortest path. Parent pointers rebuild that path backwards from the goal.

O(|V| + |E|)

iv

Play

Your walk is checked one edge at a time on the server. A move is legal only if the edge exists. Stepping straight back along the last edge counts as a backtrack.

has_edge(u, v)

v

Score

The BFS path length is a lower bound on any walk to the exit, so optimal moves over your moves is at most 1. Each hint costs 0.05 and each backtrack 0.01.

score = opt / moves - penalties
